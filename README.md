# GamePromo - Plataforma de Marketing para Videojuegos

GamePromo es una aplicación web diseñada para estudios de videojuegos indie que necesitan promocionar sus juegos en redes sociales sin un equipo de marketing dedicado.

## Características

- Subida y gestión de videos cortos y portadas
- Edición básica con plantillas prediseñadas para videojuegos
- Programación de publicaciones en YouTube Shorts, Instagram Reels y TikTok
- Interfaz intuitiva y visualmente impactante
- Análisis básico de rendimiento de publicaciones

## Estructura del Proyecto

```
/
├── public/            # Archivos estáticos
├── src/               # Código fuente
│   ├── components/    # Componentes reutilizables
│   ├── pages/         # Páginas de la aplicación
│   ├── styles/        # Estilos CSS/SCSS
│   ├── utils/         # Utilidades y funciones auxiliares
│   └── App.js         # Componente principal
├── package.json       # Dependencias y scripts
└── README.md          # Documentación
```

## Tecnologías

- React.js para el frontend
- Firebase para autenticación y almacenamiento
- Tailwind CSS para estilos
- APIs de redes sociales para publicación automática

## Instalación

```bash
npm install
npm run dev
```

## Uso

1. Sube tus videos y portadas
2. Selecciona una plantilla o personaliza tu contenido
3. Programa la publicación en las redes sociales deseadas
4. Monitorea el rendimiento de tus publicaciones
